# Diálogo CRM

- Conserva primitivas Base UI, tokens CRM y composición pública existentes.
- El popup centra el contenido y limita la altura a `100dvh - 2rem` con scroll interno.
- El contenido largo debe permitir llegar a las acciones inferiores con teclado y puntero.
- La acción de cierre se anuncia en español: "Cerrar diálogo"; el cierre del footer dice "Cerrar".
- Con movimiento reducido, el popup no reproduce animación de escala/entrada/salida.
- Los consumidores deben proporcionar un `DialogTitle` y disparadores accesibles.
