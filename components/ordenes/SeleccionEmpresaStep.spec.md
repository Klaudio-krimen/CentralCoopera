# Paso de selección de empresa

**Archivo:** `components/ordenes/SeleccionEmpresaStep.tsx`

- Permite buscar empresas y seleccionar un resultado para iniciar una orden.
- Presenta los resultados con nombre y dirección disponible, además del estado seleccionado.
- Informa consulta y selección mediante callbacks; no accede directamente a la API.
- Muestra el indicador de carga durante la consulta de empresas.
