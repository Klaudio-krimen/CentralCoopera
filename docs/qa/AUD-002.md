## Verificación real de concurrencia

PostgreSQL18 local en loopback: base exclusiva coopera_qa_aud002, schema vigente y datos
sintéticos. Se creó/verificó respaldo del esquema vacío antes de db push de QA.

Comando reproducible: cargar DATABASE_URL/DIRECT_URL de una base local coopera_qa_* y ejecutar
npm run qa:security-concurrency. Rechaza host remoto y elimina únicamente sus fixtures.

Resultado: veinte entradas paralelas; doce salidas de tres unidades producen seis éxitos y seis
conflictos 409 sin stock negativo. Ajuste y ocho entradas mantienen cadena histórica continua.
Prueba decimal conserva exactamente 0.3 como stock previo. Diez canjes paralelos de un token:
un ganador, nueve rechazos, otros tokens del usuario invalidados.
